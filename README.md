# Supermarket-Sales-and-Profit-Dashboard
An interactive Power BI dashboard analyzing supermarket revenue, profit, and customer purchasing behavior
 Supermarket Sales & Profit Dashboard

## About the Project
This interactive Power BI dashboard analyzes supermarket sales performance, profit margins, and customer payment behaviors. The goal is to provide actionable insights into category performance and city-level profitability.

## Tools & Skills Used
* Power BI
* Data Cleaning
* Data Visualization
* Dashboard Design (Orange & Green Theme)

## Key Metrics Analyzed
* **KPI Cards:** Total Revenue, Total Profit, Total Bills, and Items Sold.
* **Bar Chart:** Identified top-performing categories (Grocery and Staples lead in revenue).
* **Column Chart:** Visualized profit distribution across different cities (Ayala generates the highest profit).
* **Donut Chart:** Analyzed customer payment preferences (Cash and Credit Card are the most used).
* **Interactive Filter:** Added a customer type slicer for dynamic filtering.
